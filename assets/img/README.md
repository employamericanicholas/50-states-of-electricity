# Brand assets

Drop the official Employ America logo here as `logo.svg`, then uncomment the
`<img class="logo__mark">` line in the masthead of `index.html` to restore the
full logotype lockup.

Per Brand Guidelines 2025 p.47, the source files live in the shared drive at
`finalfiles/logos`. Use the horizontal logotype (p.7) for the masthead, or the
isotype (pp.9–10) where the full name would be repetitive. Minimum sizes are on
pp.16–17 — 65px tall for the full logo, 40px for the logomark alone. Clear space
is 30px for the horizontal lockup (p.12).

Nothing in this directory is required for the dashboard to work: the masthead
falls back to the Lato Bold wordmark, which is why no approximation of the eagle
mark is shipped here.
